# Playbook 1 หน้า — Onboard ร้าน + ไรเดอร์ โนนสูง

> มอบให้พาร์ทเนอร์ร้าน + เพื่อนไรเดอร์ ทำซ้ำได้โดยไม่ต้องพึ่งคุณทุกขั้น

## ร้านค้า (van1) — 30 นาที/ร้าน

1. **คัดร้าน:** แม่ค้ารู้จัก, มีสินค้า 5–10 รายการ, เปิด peak
2. **ลงทะเบียน:** ติดตั้ง van1 → สมัคร → ยืนยันเบอร์
3. **ตั้งร้าน:** ชื่อร้าน, เบอร์, **พิกัดร้าน** (ยืนยันบนแผนที่)
4. **สินค้า:** ลงอย่างน้อย 5 รายการ มีรูป + ราคา
5. **ทดสอบ:** สั่งทดสอบ 1 ออเดอร์ COD → รับ → preparing → ready
6. **3 วันแรก:** โทรเช้าถามว่าเห็นออเดอร์หรือไม่ — บันทึกใน `nonsung-shop-survey.csv`
7. **ปัญหา:** LINE กลุ่ม "ร้านโนนสูง" → ถ้าแอปพัง ส่ง order id ให้แอดมิน

**อย่าทำ:** เปิดร้านโดยไม่มีพิกัด / ไม่มีสินค้า / pause ออเดอร์โดยไม่แจ้ง

## ไรเดอร์ (van3) — 45 นาที/คน

1. **คัดคน:** มอไซค์, สมัคร van3 ได้, รู้เส้นทางตลาด–หอ
2. **สมัคร:** van3 → ลงทะเบียน → รอแอดมินอนุมัติ (van4)
3. **อนุมัติแล้ว:** เปิดแอป → **ออนไลน์พร้อมรับงาน** ก่อน peak 15 นาที
4. **รับงาน:** รับออเดอร์ → นำทาง two-wheeler → ส่ง → ปิดงานในแอป
5. **เวร peak:** เช้า 07–10, เย็น 16–20 (อย่างน้อย 2 คน soft launch / 3 คน expand)
6. **บันทึก:** `nonsung-rider-registry.csv` — วัน onboard, peak ที่ว่าง

**อย่าทำ:** ออนไลน์แต่ไม่รับงาน / รับงานแล้วไม่อัปเดตสถานะ

## แอดมิน (คุณ) — สัปดาห์ละครั้ง

- Seed โปร: `seed-nonsung-launch.ps1` (ครั้งเดียวตอนเปิด)
- Deploy: `deploy-plan.ps1` เท่านั้น — ไม่ deploy ช่วง peak
