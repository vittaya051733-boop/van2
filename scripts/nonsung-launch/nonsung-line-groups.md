# LINE กลุ่ม Support — ตลาดโนนสูง

สร้างด้วยมือก่อนวันเปิด (Phase 1 วันที่ 7–14)

## กลุ่มที่ต้องมี

| ชื่อกลุ่ม | สมาชิก | ใช้เมื่อ |
|-----------|--------|---------|
| **ร้านโนนสูง** | พาร์ทเนอร์ลูกแม่ค้า + ร้าน onboard แล้ว | ร้านไม่เห็นออเดอร์, pause, พิกัดผิด |
| **ไรเดอร์โนนสูง** | เพื่อนไรเดอร์ + ไรเดอร์ van3 อนุมัติแล้ว | เวร peak, ออเดอร์ค้าง, incentive |
| **แอดมิน** | คุณ + พาร์ทเนอร์ทั้งสอง (อ่านอย่างเดียวถ้าต้องการ) | deploy, refund, สรุปวัน |

## กฎการตอบ

- **ร้าน / ไรเดอร์:** พาร์ทเนอร์ตอบก่อน — คุณสำรอง 18:00–20:00
- **นอกเวลา:** auto-reply "รับเรื่องแล้ว — ตอบพรุ่งนี้ 09:00"
- **bug ระบบ:** ส่ง van4 order id + screenshot → คุณเท่านั้น

## ข้อความเปิดกลุ่ม (copy-paste)

**ร้านโนนสูง**
```
สวัสดีครับ/ค่ะ กลุ่มนี้สำหรับร้านค้าในโซนตลาดโนนสูงที่ใช้แอป van (ร้านค้า)
- แจ้งปัญหารับออเดอร์ / พิกัด / สินค้า
- เวลา peak 07–10, 16–20 น. กรุณาเปิดรับออเดอร์
ติดต่อพาร์ทเนอร์: [เบอร์พาร์ทเนอร์ร้าน]
```

**ไรเดอร์โนนสูง**
```
กลุ่มไรเดอร์ van โซนโนนสูง
- ก่อน peak ให้เปิดแอป van3 → ออนไลน์พร้อมรับงาน
- แจ้งออเดอร์ค้าง / เส้นทาง / อุบัติเหตุ
เวร peak: เช้า 07–10, เย็น 16–20
```
