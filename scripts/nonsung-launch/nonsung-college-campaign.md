# แคมเปญขยาย — วิทยาลัย + หอพัก (วัน 46–75)

## เป้า Phase 3

| ตัวชี้วัด | เป้า |
|-----------|------|
| ร้าน active | 30+ |
| ออเดอร์/วัน | 15–20 |
| ไรเดอร์ peak | 3–5 |
| นักศึกษาสั่งซ้ำ | ≥20% ภายใน 14 วันหลังออเดอร์แรก |

## โซนที่เปิดเพิ่ม

1. วิทยาลัย **2 แห่ง** ใกล้โนนสูง (จับคู่ร้านชำ + อาหาร)
2. หอพักหลัก **5–10 หอ** — จุดส่งมาตรฐาน (ชื่อหอ + โทรผู้รับ)
3. **ยังไม่เปิด** นิคมอุตสาหกรรมทั้งก้อน — เฉพาะกลุ่มเวร OT ถ้ามี demand จริง

## แคมเปญ "สั่งดึก ส่งหอ"

| รายการ | รายละเอียด |
|--------|------------|
| วัน | ศุกร์–อาทิตย์ |
| เวลา | 19:00–22:00 |
| สินค้า | ร้านชำ, ของใช้หอ, อาหารที่ยังเปิด |
| Ops | ไรเดอร์เวรอย่างน้อย 3 คน — ประกาศใน LINE ไรเดอร์โนนสูง 17:00 |
| โปร | ใช้ `nonsung_launch_banner` (ลดค่าส่ง 15%) + NONSUNG50 ถ้ายังมีสิทธิ์ |

> Backend ยังไม่มี time-window promo — รันแคมเปญด้วยการประกาศ + ไรเดอร์เวร (ไม่ต้อง deploy ใหม่)

## รายวัน Ops เพิ่ม (Phase 3)

```powershell
.\nonsung-ops-daily.ps1
```

- **18:00** — ส่งออก van4 CSV → ดูหมวดขายดี / ร้าน cancel บ่อย
- ร้านไม่มีพิกัด → ช่วยปักหมุด van1 settings ภายใน 24 ชม.
- ออเดอร์ `awaiting_rider` >15% → เพิ่มไรเดอร์หรือขยายรัศมี geo ใน seed (ไม่เกิน 12 km)

## จับคู่ร้าน–หอ

| ประเภทร้าน | หอเป้า | หมายเหตุ |
|------------|--------|----------|
| ร้านชำตลาด | หอใกล้ตลาด | lead time 30–45 นาที |
| อาหาร | หอ + วิทยาลัย | peak เย็น |
| ตลาดสด | หอที่ทำครัว | wedge — เน้นคุณภาพถ่ายรูป |

## สัญญาณหยุดขยาย

- ไรเดอร์ peak < 2 สามวันติด → หยุดโปสเตอร์หอใหม่
- ร้าน cancel > 20% → โฟกัส supply ก่อน demand
